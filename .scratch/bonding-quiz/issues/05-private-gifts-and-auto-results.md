# 05 - Private Gifts and Automatic Round Results

Category: enhancement

Status: ready-for-human

Blocked by: 02, 03, 04 (implemented locally)

## Agent Brief

Current behavior: Gift assignments expose gift names and descriptions to browsers. Round closure computes awards but waits for a separate host reveal before showing results.

Desired behavior: Gift contents remain secret for participants and the host. Assignment displays identify only the giver and recipient. Once a host starts a round, deadline expiry, all twenty non-author submissions, or an early host closure automatically publish the answer result, winner, and giver-only assignment. The host still cues the next round; no automatic start or advance.

Key interfaces: `GameState` and `GiftAssignment` must not serialize gift contents. Round reconciliation must atomically close, allocate, and publish results. Existing closed-but-unrevealed rounds must recover without manual reveal or duplicate awards.
