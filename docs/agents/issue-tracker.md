# Issue Tracker: Local Markdown

- Spec: .scratch/<feature>/spec.md.
- One file per ticket: .scratch/<feature>/issues/NN-<slug>.md.
- Record status using a Status: line.
- Record dependencies using a Blocked by: line.
- Work on blockers before dependent tickets.
- Append discussion under ## Comments.
- Publishing or fetching issues means writing or reading
  these local files; no external tracker is required.
